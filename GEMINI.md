# MyShisha.vip - Developer Context

You are assisting in the development of **MyShisha.vip**, a platform for shisha lovers to journal sessions, discover lounges, and manage equipment.

## Origins
This project was forked from `viditacafe` and adapted for the shisha domain.

## Architecture
- **Web**: Next.js / TypeScript static application (Served via Backend).
- **Backend**: High-performance C++ server (Drogon + Glaze + PostgreSQL).

## Critical Documents
1. **PLAN.md**: The roadmap for the shisha adaptation.
2. **SPECIFICATION.md**: (Pending update) Functional requirements.
3. **GOALS.md**: (Pending update) High-level objectives.

## Safety & Infrastructure
- **CI/CD**: Original workflows removed. Do NOT deploy to Vidita Cafe infrastructure.
- **Environment**: Use local `flake.nix` in each subdirectory.
